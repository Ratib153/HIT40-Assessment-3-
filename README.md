# Task 2.1 - Predicting Goal Difference

## Objective

Task 2.1 investigates whether information available before a FIFA World Cup 2026 match can be used to predict the **goal difference between Team A and Team B**.

The unit of observation is one match.

The final Task 2.1 dataset contains:

| Item | Value |
|---|---:|
| Observations | 104 matches |
| Response variable | 1 |
| Starting explanatory variables | 8 |
| Missing predictor values | 0 |

---

## Response Variable

### `goal_diff`

Goal difference is calculated as:

```text
Team A goals - Team B goals
```

Extra-time goals are included in the final match score.

Penalty shootout kicks are not included.

---

## Task 2.1 Starting Explanatory Variables

| Variable | Description |
|---|---|
| `fifa_points_diff` | Team A FIFA ranking points minus Team B FIFA ranking points |
| `market_value_log_ratio` | Natural log of Team A squad market value divided by Team B squad market value |
| `squad_age_diff` | Difference in average squad age between Team A and Team B |
| `rest_days_log_ratio` | Natural log of Team A rest days divided by Team B rest days |
| `host_diff` | Difference in host-country status between Team A and Team B |
| `travel_1000km_diff` | Difference in travel distance to the stadium, measured in thousands of kilometres |
| `tournament_form_diff` | Difference in average goal difference from earlier World Cup 2026 matches |
| `pre_wc_form_diff` | Difference in average goal difference from 2026 internationals before the World Cup |

The model starts with exactly eight explanatory variables.

# Task 2.2 - Predicting Goals Scored

## Objective

Task 2.2 investigates whether pre-match information can be used to predict the **number of goals scored by a team in a FIFA World Cup 2026 match**.

The unit of observation is one team in one match.

Each of the 104 tournament matches therefore appears twice, once from the perspective of each team.

The final Task 2.2 dataset contains:

| Item | Value |
|---|---:|
| Observations | 208 team-match rows |
| Matches | 104 |
| Teams | 48 |
| Response variable | 1 |
| Starting explanatory variables | 8 |
| Missing predictor values | 0 |

---

## Response Variable

### `goals_scored`

The number of goals scored by the team in the match.

Penalty shootout kicks are not included.

---

## Task 2.2 Starting Explanatory Variables

| Variable | Description |
|---|---|
| `fifa_points_diff` | Team FIFA ranking points minus opponent FIFA ranking points |
| `rest_days` | Number of days since the team's previous senior international |
| `venue_altitude_m` | Stadium elevation above sea level in metres |
| `attacking_form_5` | Average goals scored by the team in its previous five senior internationals |
| `opponent_defensive_form_5` | Average goals conceded by the opponent in its previous five senior internationals |
| `previous_extra_time` | Whether the team's previous match went beyond 90 minutes |
| `lineup_changes` | Number of current starters who did not start the team's previous match |
| `qualification_pressure` | Tournament-stage proxy for increased qualification or elimination pressure |

For `qualification_pressure`:

```text
0 = first or second group-stage match
1 = third group-stage match or any knockout match
```

`lineup_changes` becomes available after the official starting XI is announced but before kickoff.

Task 2.2 therefore defines the prediction point as **after lineups are announced and before the match begins**.

### Preparation stages

**`01_prepare_matches.py`**

Cleans the World Cup match data and creates the 104-match tournament dataset.

**`02_create_team_matches.py`**

Transforms the 104 matches into 208 team-match observations.

Each match therefore produces:

```text
Team A perspective
Team B perspective
```

**`03_add_fifa_strength.py`**

Adds FIFA ranking information from the ranking released immediately before the World Cup and calculates:

```text
fifa_points_diff
```

**`04a_create_venue_altitudes.py`**

Creates the venue altitude data programmatically.

World Cup venue names are extracted from the cleaned match data.

The Python `geopy` library queries OpenStreetMap Nominatim for stadium coordinates.

Those coordinates are then submitted to the Open-Elevation API, which returns elevation values from its SRTM elevation dataset.

The script produces:

```text
data/raw/venue_altitudes.csv
data/raw/venue_altitude_source_audit.csv
```

**`04b_add_venue_altitude.py`**

Adds the programmatically retrieved stadium elevations to the team-match dataset.

**`05_add_historical_features.py`**

Uses historical international match data to calculate:

```text
rest_days
attacking_form_5
opponent_defensive_form_5
previous_extra_time
```

Only matches that occurred before the match being predicted are used.

**`06_prepare_lineup_data.py`**

Extracts World Cup starting XIs and identifies the previous match required for each team's first World Cup lineup comparison.

**`07_combine_pre_world_cup_starters.py`**

Combines the available pre-tournament starting-lineup records.

**`08_add_lineup_changes.py`**

Calculates:

```text
lineup_changes
```

as:

```text
11 - number of starters retained from the previous match
```

**`09_add_qualification_pressure.py`**

Creates the tournament-stage pressure proxy and produces the final model-ready dataset.

**`10_final_dataset_audit.py`**

Checks the final dataset for structural, missing-value and range problems.

**`11_dataset_documentation.py`**

Creates the Task 2.2 variable dictionary.

Therefore, the selected pre-match variables provide useful predictive information, but a substantial amount of match-to-match variation in goals remains unexplained.

# Leakage Prevention and Pre-Match Availability

Particular care was taken to prevent information from the match being predicted from entering the explanatory variables.

Historical form calculations use only matches that occurred before the current match.

FIFA ranking points come from the ranking released before the World Cup.

Task 2.1 tournament form uses only earlier tournament matches.

Task 2.2 lineup changes use starting-lineup information available before kickoff.

Current-match extra-time and penalty-shootout indicators are not included as explanatory variables.

For Task 2.2, grouped cross-validation prevents the two observations from the same match appearing in different folds.
