HIT140 Assessment 3 - Task 2.2
DATA SOURCES AND PROVENANCE

This file records where the raw data used for Task 2.2 came from.
The Python scripts in this folder perform the cleaning, feature engineering,
validation and modelling. The raw source files are stored under data/raw/.

4. WORLD CUP VENUE ALTITUDE
----------------------------------------------------------------------

Local file:
data/raw/venue_altitudes.csv

Used for:
- venue_altitude_m

Collection method:
This was not downloaded as one ready-made dataset from a single website.
The venue-altitude lookup was manually compiled for the project with
assistance from ChatGPT using publicly available stadium/location
information, and then saved as venue_altitudes.csv.

ChatGPT:
https://chatgpt.com/

Because this file was manually compiled rather than downloaded from one
specific webpage, there is no single original dataset URL for it.


----------------------------------------------------------------------
5. FIFA WORLD CUP 2026 STARTING LINEUPS
----------------------------------------------------------------------

Local files:
data/raw/lineups/matches.csv
data/raw/lineups/match_appearances.csv

Used for:
- World Cup starting XIs
- player IDs
- lineup_changes for matches after each team's first World Cup match

Source:
FIFA Training Centre match reports

FIFA Training Centre:
https://www.fifatrainingcentre.com/

Important:
The exact FIFA Training Centre PDF URL for every one of the 104 World Cup
matches is already stored in:

data/raw/lineups/matches.csv

under the column:

source_url

For example, Match 1 is stored as:
https://www.fifatrainingcentre.com/media/native/tournaments/fifa-world-cup/2026/PMSR-M01%20MEX%20V%20RSA.pdf

The project keeps the exact per-match source URLs in the raw CSV rather than
duplicating all 104 URLs in this text file.

----------------------------------------------------------------------
8. CHATGPT / AI ASSISTANCE DISCLOSURE
----------------------------------------------------------------------

ChatGPT was used as an assistance tool for a small amount of supplementary
data collection and checking during Task 2.2.

In particular, ChatGPT assisted with:
- compiling the venue altitude lookup
- helping locate/check some fallback pre-World-Cup lineup records when a
  usable Cornerflick file was unavailable
- checking data consistency and helping organise the Python workflow

ChatGPT was NOT the primary source for:
- the World Cup match results
- FIFA ranking points
- the historical international match dataset
- FIFA Training Centre World Cup lineups
- the 24 downloaded Cornerflick lineup files

Where fallback lineup information was used, the underlying external source
name and URL are preserved in:
data/raw/lineups/pre_world_cup_starters_fallback.csv

The data preparation and modelling steps are implemented in the Python
scripts included with the project.
